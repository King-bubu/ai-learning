# archive 是什么

**就是一个普通文件夹，名字叫「归档」。** 东西没删，只是不摆在桌面上了。

这里放的是**完成使命的历史脚本**。判断标准很简单：**没有任何文件 import 它们**，所以挪到这里不会破坏任何东西（挪之前我跑过一次实测确认）。

---

## 为什么改了名

原来叫 `day9_rank`、`day9_topk`、`day9_wordfreq`、`day9_ablation` —— 全是行话。

行话的用途是让懂行的人少打几个字，不是让人看懂。所以改成了「它干什么」。

| 现在叫 | 原来叫 | 行话的意思 | 它实际打印什么 |
|---|---|---|---|
| `day09_正确段排第几.py` | `day9_rank` | rank = 排名 | 第1题 最高分7 并列1段 正确段排第1 |
| `day09_取几段.py` | `day9_topk` | top-k = 取前 k 个 | k=1 9/10 错[6] / k=2 10/10 |
| `day09_哪些词到处都是.py` | `day9_wordfreq` | word frequency = 词频 | 总段数12 / 「的」出现在12段 |
| `day09_拿掉一个词.py` | `day9_ablation` | ablation = 消融（医学：切除） | 删掉什么 8/10 |
| `day08_最早的量分.py` | `day8_eval_run` | eval = 评测 | raw 8/10 norm 6/10 sqrt 8/10 |
| `day11_同一题问3次.py` | `day11_stability` | stability = 稳定性 | 三次回答是不是一模一样 |
| `day11_给假资料会怎样.py` | `day11_fake` | — | 模型会不会照抄错数字 |

Day 1–5 那几个（`day01_pandas入门` 到 `day05_包成类`）是同一天学会的证据，只是不再参与今天的工作了。

## 如果哪天要重跑它们

**必须在项目根目录运行**，并且告诉 Python 去哪找核心文件：

```powershell
$env:PYTHONPATH="."
python archive/day09_取几段.py
```

为什么需要这么麻烦，两个原因：

1. 脚本第一行 `from day06_files import ChatBot` —— Python 默认只在**脚本自己所在的目录**里找，而 `archive/` 里没有 `day06_files.py`。`PYTHONPATH` 就是给它指路。
2. `ChatBot` 里 `Path("docs")` 是**相对路径**，它按你**当前站在哪个目录**去找资料。所以你人必须站在根目录。

> 这两条合起来就是一句话：**代码和资料，各按各的规矩找对方。**

## 以后所有脚本怎么起名（新规矩）

```
dayNN_它干什么.py
```

- 好：`day12_比较两种切词.py` → 一眼知道要比较什么
- 坏：`day12_tokenizer_compare.py` → 又要背行话

判断方法：**想象三个月后的自己打开这个文件夹，只看得见文件名，猜不猜得到它会打印什么。**

## 别做这几件事

- **别 `rm` 这里的东西。** 它们是你 11 天的证据，不是垃圾。
- **别在主目录 import 这里的东西。** 归档区的文件不再被依赖，这是它作为归档的意义。
- **挪新文件进来之前，先 `grep` 一下有没有人 import 它。** 有人 import 就不能挪。
